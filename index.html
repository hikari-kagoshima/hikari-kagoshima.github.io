ABOUT

HIKARI project

HIKARI project は、子どもの育ちを、からだと脳のしくみから見つめ、遊びと運動で伸ばしていく場所です。

からだを動かす。よく見る。考える。友だちと関わる。
子どもは遊びの中で、そのぜんぶを同時に育てています。
すべての子どもに、伸びていく力があります。

「これでいいのかな？」
子育ての小さな不安を、私たちも親として何度も感じてきました。
だからこそ、子どもたちが自分で選択できる未来へ進めるように、親として、専門職として寄り添います。

ビジョントレーニングべすとびじょん式｜認定アンバサダー・プロトレーナーが担当 運動あそび作業療法士・理学療法士が担当 コグトレからだを動かすコグトレも取り入れます 学研教室別料金

いちばん大切にしているのは、変化を出すこと。

保護者の方と目標を決め、変化を一緒に確かめるところまでを、ひとつの流れにしています。

  1. 01評価運動・見る力・認知の評価を行います（別料金）。
  2. 02目標を決める保護者の方と一緒に、暮らしの中の具体的な目標を決めます。
  3. 03プログラム目標に合わせて、運動あそび・ビジョントレーニング・コグトレを組み合わせます。
  4. 04変化を確かめるはじめに決めた目標に照らして、変化を一緒に振り返ります。
